# 🎮 Mom's Arcade — SeaQuest

A faithful HTML5 Canvas recreation of the Atari 2600 classic **SeaQuest**, built as a PWA for iOS/Android.

## How to Play
- Guide your submarine to rescue green divers
- Return to the surface to deliver divers and refill oxygen
- Shoot or avoid sharks, squid, and eels
- Watch your oxygen meter — if it runs out, you die!

## Controls
- **Desktop:** Arrow keys to move, Spacebar to fire
- **Mobile:** On-screen D-pad + FIRE button (auto-detected on touch devices)

## Install on iPhone
1. Open the URL in Safari
2. Tap the Share button
3. "Add to Home Screen"
4. Plays fullscreen, works offline

## Tech
- Pure vanilla JavaScript — no frameworks, no dependencies
- HTML5 Canvas at 192×220 (scaled, pixel-perfect)
- Web Audio API for retro sound effects
- PWA manifest + service worker for offline play
